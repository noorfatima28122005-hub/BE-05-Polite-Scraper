# The Polite Scraper

## Target Classification

**Target:** Books to Scrape  
**URL:** https://books.toscrape.com/  
**Purpose:** Public practice sandbox for web scraping.

Books to Scrape identifies itself as a demo website for web scraping purposes and is designed for practicing scraping.

**Scope:** I will scrape only the first 3 catalogue pages and the 60 book pages linked from those pages.

**Data collected:** title, product URL, price, availability, rating, description, source page, and fetch timestamp.

**Robots check:** no robots file found (`/robots.txt` returned 404 Not Found).

**Why this is appropriate:** This target is a public practice sandbox specifically designed for learning and practicing web scraping, so it is appropriate for this assignment.

I will not reuse this code on another site without checking its rules and terms first.
